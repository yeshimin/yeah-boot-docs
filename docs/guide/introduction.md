# 项目介绍

YeahBoot 是一套面向后台管理与 App 配套服务的前后端分离基础项目。它优先解决真实项目中会反复遇到的认证、权限、组织关系、文件存储、日志和系统参数问题，同时保持代码直接、模块边界明确。

## 项目组成

| 仓库              | 作用     | 主要技术                                               |
| ----------------- | -------- | ------------------------------------------------------ |
| `yeah-boot`       | 后端服务 | Java 8、Spring Boot 2.7、Spring Security、MyBatis-Plus |
| `yeah-boot-admin` | 管理后台 | Vue 3、TypeScript、Vite、Element Plus、Pinia           |
| `yeah-boot-site`  | 官方主站 | 原生 HTML、CSS、JavaScript                             |
| `yeah-boot-docs`  | 官方文档 | VitePress                                              |

## 已具备的能力

- 管理后台用户名密码登录、图形验证码和登录失败临时限制。
- App 手机号密码或短信验证码登录。
- JWT 签名验证与 Redis 服务端 Token 状态控制。
- 用户、角色、资源、组织、岗位、字典、地区、文件、存储、日志和系统参数管理。
- 视图资源、接口资源、接口分组和多对多挂载。
- 本地、七牛和 MinIO 存储实现。
- 统一返回、全局异常、Trace ID、接口日志、系统日志、限流和敏感数据处理。
- 用户 Excel 模板下载、导入和按条件或勾选导出。
- Admin 与 App 单入口或双入口组织方式。

## 设计取向

项目优先使用成熟版本，不以追逐最新版本为目标。通用能力会抽取，但不会为了形式完整引入不必要的接口层、适配层或复杂缓存。

## 适用场景

- 中小型企业后台、运营平台和内部管理系统。
- 需要角色权限与组织岗位关系的管理系统。
- App、H5 或小程序的配套服务端基础工程。
- 定制交付项目的起始模板。
- 学习 Spring Boot 与 Vue 前后端分离工程的参考项目。

## 使用前须知

YeahBoot 是基础项目，不是覆盖所有行业场景的成品。生产使用前仍需要根据业务完成：

1. 替换所有开发环境凭据与默认账号。
2. 按业务重新设计角色、资源和数据范围。
3. 增加自动化测试、监控、备份与容量评估。
4. 对公开接口补充业务级防刷、风控和审计。
5. 对文件、短信等外部资源设置额度和生命周期策略。
