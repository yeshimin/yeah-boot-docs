# 字典管理

字典用于管理状态、类型和展示文本等可枚举业务值。字典表本身使用字符串保存值，但业务表应根据字段语义选择 Integer、String 或 Boolean，不要求所有字段都使用同一种数据库类型。

## 树形结构

字典支持多级父子关系。典型结构：

```text
用户状态
├── 1 / 启用
└── 2 / 禁用
```

编辑节点时允许更换上级，但新上级不能是自身或后代节点。前端树选择器应禁用这些非法候选项，而不是禁用所有祖先。

## 创建和编辑

建议维护：

- 编码：程序或业务识别值。
- 名称：页面展示内容。
- 状态：是否允许继续使用。
- 排序：同级展示顺序。
- 备注：使用范围和约束。

业务中高频、强约束的核心枚举应保留代码 Enum；需要运营调整的展示字典适合数据库维护。不要为了“统一字典”把所有布尔值和内部协议枚举都变成字符串。

## 删除

删除父节点会影响整棵子树。页面应在检测到子节点时提示删除范围，并要求二次确认；确认后可以由后端执行明确的强制删除策略。

地区数据不复用字典删除规则。地区按编码关联，当前不做复杂跨表关联检查。

## 使用建议

- 状态编码发布后尽量保持稳定。
- 禁用用于停止新选择，历史数据仍应能正确回显。
- 前端不要只显示编码，应映射为可读名称。
- 删除前先确认没有外部系统依赖该编码。
