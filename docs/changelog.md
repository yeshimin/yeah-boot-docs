# 更新日志

本页记录适合公开说明的重要变化；细粒度修改以各仓库 Git 提交记录为准。

## 当前阶段

- 完善用户、角色、资源、组织、岗位、字典、地区、文件和存储管理。
- 增加系统日志详情与系统参数管理。
- 视图资源、接口资源分层管理，支持接口分组和多对多挂载。
- 权限标识使用 `view:` 与 `api:` 命名约定。
- 角色授权支持视图资源 ID 和接口挂载 ID。
- JWT 与 Redis 联合维护服务端 Token。
- 禁用用户强制下线，角色和资源状态请求时实时生效。
- 增加登录失败限制和管理员解除入口。
- 增加 Trace ID、敏感数据注解和日志脱敏。
- 增加逻辑删除时间自动填充。
- 增加用户 Excel 模板、导入和导出。
- 增加首页并统一管理页面交互。
- 建立独立官网和 VitePress 文档站。

## 版本发布建议

正式对外发布后按语义版本维护：

- Major：不兼容的架构或接口变更。
- Minor：向后兼容的新功能。
- Patch：向后兼容的问题修复。

每个版本至少记录数据库迁移、配置变化、权限资源变化和升级注意事项。
